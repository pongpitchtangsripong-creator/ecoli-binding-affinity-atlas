# E. coli Binding & Affinity Atlas

Interactive, evidence-graded comparison of:

1. Chloramphenicol + E. coli 50S ribosomal subunit
2. Ribosomal 50S catalytic centre + native A/P-site tRNAs
3. Cefuroxime + E. coli PBP3 (FtsI)
4. E. coli PBP3 + native peptidoglycan stem substrate

The site distinguishes equilibrium affinity, apparent IC50, and unavailable native-substrate affinity rather than treating them as directly interchangeable. The molecular viewers support rotation, zooming, binding-site focus, contact lines, interaction-zone surfaces, and labels.

## Scientific-use note

This is a mechanistic visualization, not a clinical dosing tool. Cefuroxime IC50app is not a thermodynamic Kd, and tRNA affinity depends on ribosomal site and assay context. The PBP3 native-substrate affinity is reported as not determined rather than imputed.

Primary literature and structural database links are included in the web page.
